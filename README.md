Dengue Outbreak Prediction Dashboard

Project Overview

This project explores the use of machine learning and environmental data to support dengue case prediction and outbreak risk analysis.

Objectives

- Prepare and analyze historical dengue data.
- Explore relationships between environmental factors and dengue cases.
- Build a machine learning model to estimate dengue cases.
- Present predictions and data visualizations through an interactive dashboard.

Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- HTML and CSS

Key Features

- Interactive dashboard for exploring dengue prediction results.
- Machine learning-based case estimation.
- Visualizations to support exploratory data analysis.
- Historical data analysis involving environmental variables.

Getting Started

1. Clone this repository:
   git clone YOUR_REPOSITORY_URL
2. Navigate to the project folder:
   cd YOUR_PROJECT_FOLDER
3. Install the dependencies:
   pip install -r requirements.txt
4. Start the Flask application:
   python app.py
5. Open the local URL displayed in your terminal.
